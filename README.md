# Srishti Sangayya Malimath — Personal Portfolio

An ultra-modern, high-performance personal portfolio website engineered for **Srishti Sangayya Malimath**, AI & ML Engineering undergraduate at CMR Institute of Technology, Bengaluru.

Featuring a cyber-aesthetic glassmorphism UI, interactive AI agent simulator, real-time project deep-dive modals, live resume preview, and dark/light adaptive theme.

---

## 🌟 Key Highlights & Features

- **Interactive AI Agent Simulator (`Srishti AI Agent v1.0`)**: A simulated prompt terminal allowing recruiters and visitors to interactively query Srishti's skills, agentic workflows, MCP expertise, and background with sub-millisecond response time.
- **Glassmorphic Cyber-Clean Design**: Tailored visual hierarchy with dynamic gradient mesh lighting, ambient floating orbs, and responsive cards.
- **Interactive Project Architecture Modals**: Deep-dive case studies for each featured project with architecture workflows, engineering challenges, and quantified metrics (>80% time saved, real-time FFT frequency detection, balanced ML precision).
- **Direct Resume Viewer & Downloader**: In-page modal preview for Srishti's verified resume PDF with one-click direct download.
- **Dark / Light Theme Toggle**: Seamless toggle with local storage persistence and automated system preference detection.
- **Direct Contact & 1-Click Copy**: Instant clipboard copying for email and phone with visual toast alerts, plus an interactive contact form.

## 🚀 How to Run Locally

### Option 1: Streamlit App (Python)
```bash
streamlit run app.py
```
Opens automatically in your browser at `http://localhost:8501`.

### Option 2: Direct Browser Launch (HTML)
Simply double-click `index.html` or open it with any web browser.

### Option 3: Local HTTP Server (Python)
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

## 🌐 Deploy Online

### Deploy on Streamlit Community Cloud (Free & 1-Click)
1. Push this repository to GitHub (`https://github.com/Srishti-2005/portfolio`).
2. Visit **[share.streamlit.io](https://share.streamlit.io)** and log in with GitHub.
3. Click **"New app"**, select your repository, set the main file to `app.py`, and click **"Deploy"**.
4. Live at `https://<your-app>.streamlit.app`!

### Deploy on GitHub Pages
1. Push this repository to GitHub under `https://github.com/Srishti-2005/portfolio`.
2. Go to **Settings > Pages** and select branch `main` root `/`.
3. Live at `https://srishti-2005.github.io/portfolio/`.

### Deploy on Vercel / Netlify
- **Vercel**: Run `npx vercel` or import from GitHub.
- **Netlify**: Drag and drop the folder on [app.netlify.com/drop](https://app.netlify.com/drop).
